# 常见问题

## 改了代码 / 换了安装包，但好像没生效？

应用有**单实例锁**：旧的 DeskLLMPet 还在运行时，再启动一次会被直接拦掉并退出，跑的还是旧代码。

1. 在托盘菜单点「退出」关掉旧实例；
2. 再运行 `npm run dev` 或启动新安装包；
3. 启动时终端第一行会打印代码目录与版本：
   ```text
   🚀 DeskLLMPet 启动 v<version> | 代码目录: /path/to/DeskLLMPet | 参数: . --dev
   ```
4. 设置 → 关于 里也能看到**运行目录**和版本号，用来确认跑的是哪份代码。

## 设置页的版本号和安装包不一致？

设置页版本号来自主进程的 `app.getVersion()`，也就是 `package.json` 的 `version`。如果显示旧版本，说明启动的是旧的安装包或旧实例。

## macOS 提示「已损坏」/「无法验证开发者」

安装包未做代码签名和公证：

- 首次打开：右键 `DeskLLMPet.app` → 打开；
- 或到 **系统设置 → 隐私与安全性** 点 **仍要打开**；
- 实在不行：`xattr -dr com.apple.quarantine /Applications/DeskLLMPet.app`。

## Windows 弹出 SmartScreen

点「更多信息」→「仍要运行」。安装包未做 Windows 代码签名。

## 动画不显示 / 只有占位动画？

- 检查 `.webm` 是否在 `assets/animations/idle/` 或 `assets/animations/click/`；
- 确认是带透明通道的 VP8/VP9 WebM；
- 设置 → 动画素材里看文件是否被扫描到、是否勾选；
- 重启应用或重新打开设置页刷新列表。

## 气泡被窗口裁掉 / 挡住宠物？

气泡是独立窗口，默认浮在宠物上方。到 **设置 → 宠物设置 → 气泡显示** 调整大小和偏移，或点「重置气泡」。

## 右键菜单跑到别处 / 菜单太长？

菜单是独立窗口，会贴着鼠标展开并收敛在屏幕可用区域内；插件菜单项超过一屏时在菜单内部滚动。如果仍有问题，请附系统版本、缩放比例和截图提 Issue。

## 插件安装后没有出现？

- 设置 → 插件 列表里看状态：`已启用` / `已禁用` / `加载失败`；
- 加载失败会显示原因，终端也会打印 `⚠️ 插件加载失败 [id]: ...`；
- 确认插件包与当前应用版本兼容（`apiVersion`）；
- 点「重新扫描」或重启应用；
- 仍不行就卸载后重新安装，并在 Issue 里附上插件包与日志。

## 插件会影响本体吗？

插件在主进程中运行，权限与本体相同，**不是沙箱**。请只安装可信来源的插件；插件加载失败只会跳过该插件，不影响本体启动。

## 数据存在哪里？

Electron 的 `userData` 目录：

- 本体配置：`config.json`
- 已安装插件：`plugins/`
- 插件数据：`plugin-data/`
- 插件安装状态：`plugins-state.json`

设置 → 插件 里会显示实际路径，并提供「打开插件目录」。
