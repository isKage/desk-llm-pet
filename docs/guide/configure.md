# API 与桌宠配置

所有配置都在 **右键桌宠 → 设置**（或托盘菜单 → 设置）中完成，保存后即时生效。

## 1. API 配置（用于余额查询）

打开 **设置 → 🔑 API 配置**：

| 配置项 | 说明 |
|---|---|
| API Key | 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建，形如 `sk-xxxx` |
| API 地址 | 默认 `https://api.deepseek.com`，余额接口按「域名 + `/user/balance`」自动推导 |
| 余额查询地址（可选） | 使用代理或自建服务时填写；留空则按上方地址推导 |

配置后：

- **双击**桌宠 → 气泡展示当前余额（单击只播放点击反应动画）；
- 默认每 30 分钟自动展示一次，可在 **设置 → 宠物设置 → 余额气泡** 调整间隔；
- 托盘菜单「立即查看 API 余额」也可手动触发；
- 关闭「启用余额气泡」后，双击桌宠会从「双击自定义语句」里随机展示一句。

> 🔒 API 密钥仅保存在本地，不会上传到任何服务器。

### AI 对话的配置

AI 对话是内置插件，有独立配置页：**设置 → 💬 AI 对话**。

| 配置项 | 说明 |
|---|---|
| API Key / API 地址 | 留空则自动回退使用「API 配置」里的值，通常不用重复填写 |
| 模型 | 默认 `deepseek-chat`，也可填 `deepseek-reasoner` |
| temperature / max_tokens | 回复的随机性与长度上限 |
| 流式输出 | 开启后逐字显示，可随时「停止生成」 |
| 系统提示词 | 定义 AI 的身份与回答风格 |

面板上的 **🔗 测试连接** 可直接验证配置是否可用。

## 2. 动画素材

**设置 → 🎬 动画素材** 可以勾选启用哪些动画：

- **闲置动画池**：桌宠空闲时随机播放；
- **点击反应动画池**：单击桌宠时随机播放。

默认全部启用。新增 `.webm` 文件的方法见 [自定义图标与动画](customize.md)。

## 3. 宠物设置

**设置 → 🐾 宠物设置**：

- **透明度**：0.2 ~ 1。
- **宠物大小**：0.5 ~ 2 倍，只改变宠物本身，不改变窗口包围程度。
- **窗口裁剪**：窗口边长 = `300 × 宠物大小 × 裁剪比例`，默认 55%。
  - 「画面水平/垂直偏移」用于把动画主体对准窗口中心。
  - 拖动滑块即时预览，防抖写盘。
- **气泡大小 / 偏移**：气泡是独立悬浮窗，默认浮在宠物上方，不挡鼠标。
  - 可点「预览气泡」看效果，或「重置气泡」恢复默认。
- **余额气泡**：开关、自动展示间隔 t（分钟，0 表示只在双击时展示）、双击自定义语句。
- **开机自启动**：登录系统时自动运行。

保存宠物设置会同时保存余额气泡与气泡位置配置。

## 4. 托盘与右键菜单

- **单击托盘图标**：显示 / 隐藏桌宠。
- **双击托盘图标**：显示桌宠。
- **右键托盘 / 右键桌宠**：菜单。
- 插件可以往两个菜单里加条目；菜单项多到超过一屏时，菜单内部会滚动。
