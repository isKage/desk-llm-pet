# 安装与管理插件

DeskLLMPet 的插件：下载一个插件包，放进插件目录并在应用里安装/启用即可，**不需要改项目代码**。

> 🛒 **探索更多插件**：到 [DeskLLMPet 插件市场](https://github.com/isKage/desk-llm-pet-plugins-market) 浏览官方与社区插件。
> 从市场下载 `.dlmpet` 后，按下面的步骤安装即可；市场仓库里也会说明每个插件的用途和兼容版本。

## 1. 插件目录

| 内容 | 路径 |
|---|---|
| 用户插件代码 | `app.getPath('userData')/plugins/` |
| 插件私有数据 | `app.getPath('userData')/plugin-data/<id>/` |
| 安装状态 | `app.getPath('userData')/plugins-state.json` |
| 内置插件（只读） | 应用安装目录里的 `src/plugins/`（打包后位于 `app.asar`） |

实际路径以 **设置 → 🧩 插件** 顶部显示为准，点「📂 打开插件目录」可直接打开。

> 开发模式和安装版都使用 Electron 的 `userData` 目录，**不是仓库里的 `src/plugins`**。所以安装插件不会修改项目文件，升级应用也不会覆盖插件。

## 2. 安装方式

### 方式一：设置页选择插件包（推荐）

1. 下载 `.dlmpet`（或 `.zip`）插件包；
2. 打开 **设置 → 🧩 插件**；
3. 点「📥 选择插件包…」，选中文件；
4. 预览插件名称、版本、作者、大小和 SHA-256；
5. 勾选「我确认该插件包来自可信来源」，点「安装」；
6. 安装完成后插件会立即出现在列表、右键菜单和托盘菜单里（无需重启）。

### 方式二：拖拽

把插件包拖到设置页的虚线区域，后续步骤同上。

### 方式三：手动放进插件目录（Minecraft 式）

1. 点「📂 打开插件目录」，把 `.dlmpet` / `.zip` 文件复制进去；
2. 重启应用，或回到设置页点「🔄 重新扫描」；
3. 应用会自动解包、安装并加载。

也可以直接放入一个已解压的插件文件夹（里面要有 `plugin.json`），应用会把它当作「手动放入」插件加载。

## 3. 管理插件

在 **设置 → 🧩 插件** 的列表里：

| 操作 | 说明 |
|---|---|
| 启用 / 禁用 | 禁用会关闭该插件的窗口并从菜单/设置页移除；数据保留 |
| 设置 | 跳到该插件的配置面板（如果插件声明了 `contributes.settings`） |
| 目录 | 打开用户插件目录（内置插件不可用） |
| 卸载 | 仅用户安装/手动放入的插件；可选择是否同时删除插件数据 |
| 重新扫描 | 重新读取插件目录、自动安装放进去的包、热重载 |

内置插件（如 AI 对话）显示「内置」徽章：可以禁用，但不能卸载。若插件在 `plugin.json` 里写了 `"enabled": false`，会显示为作者禁用，UI 不允许开启。

## 4. 更新插件

用新版本插件包再次安装即可：

- 预览会显示已安装版本；
- 同版本覆盖需要确认；
- 降级会显示警告；
- 插件数据默认保留；
- 旧版本目录会备份到 `.trash/`，重启后清理。

## 5. 安全提示

- 插件在主进程中运行，**拥有与本机相同的权限，没有沙箱**；
- 只安装来自可信作者、可信来源的插件包；
- 安装预览会显示 SHA-256 前 12 位，但 v1 不做签名校验；
- 不认识的插件不要安装；有疑问先在 Issue / 作者主页确认。

## 6. 故障排查

| 现象 | 处理 |
|---|---|
| 列表显示「加载失败」 | 展开错误信息，终端也会打印 `⚠️ 插件加载失败 [id]: ...`；确认入口文件/依赖/`apiVersion` |
| 安装后菜单没出现 | 看插件是否「已启用」；点「重新扫描」；重启应用 |
| 提示与内置插件冲突 | 换一个插件 id；内置插件优先 |
| 提示 `UNSAFE_ENTRY` / `INVALID_PACKAGE` | 插件包损坏或结构不对，重新下载/重新打包 |
| 提示权限不足 | 检查 `userData` 目录写权限，或用「打开插件目录」确认位置 |
| 卸载提示文件占用 | 关闭插件窗口后重试；仍失败时重启应用，应用会清理 `.trash` |
